
# RN-News 📱
A modern, cross-platform mobile news application built with React Native and Expo. Stay updated with the latest news from various categories in a clean, user-friendly interface.

## ✨ Features
*   **Article Details**: View full articles with image and descriptions.
*   **Cross-Platform**: Works on both iOS and Android devices.

## 🛠️ Tech Stack
*   **React Native** - Mobile framework
*   **Expo** - Development platform
*   **React Navigation** - Screen management
*   **Custom Hooks** - For logic and API calls

## 📋 Prerequisites
*   Node.js (v16 or newer)
*   npm
*   Expo Go app on your physical device (optional)
